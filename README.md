# Bharat Marko - Facts Studio

A starter Android app project for creating YouTube Facts content.

## Build an APK using GitHub (Android phone friendly)

1. Download and extract this ZIP on your phone.
2. Create a new GitHub repository named `bharat-marko-facts-studio`.
3. Upload the **contents** of this folder to the repository (not the ZIP file itself).
   Keep the folder structure exactly as shown.
4. Open the repository's **Actions** tab.
5. Select **Build Android APK** and tap **Run workflow**.
6. Wait for the workflow to finish successfully.
7. Open the completed workflow run, scroll to **Artifacts**, and download `BharatMarko-FactsStudio-debug-apk`.
8. Extract the downloaded artifact ZIP and install the APK on your Android phone.

If GitHub asks for permission to run workflows, allow it for your repository.

## Features in this starter version
- Hindi/English topic input
- Generate a sample facts script, title, description, hashtags and tags
- Copy generated text
- Works offline after installation

Note: This first version uses built-in templates. It does not call an AI service. AI generation can be added later with a secure backend.
